# Раскрывающиеся категории

Дата: 17 сентября 2026. Рабочий вариант: design-v3. Предыдущий снимок: v3.2.

Проверено в Codex In-app Browser через CUA / Playwright:

- Все 12 категорий открываются, каждая содержит шесть ссылок и переход в каталог.
- Три карточки в ряд на десктопе; раскрытая карточка занимает свободное место между двумя сжатыми соседями. Высота ряда остаётся 420 px. Полосы шириной 72 px (58 px на планшетной ширине), без изображений, с вертикальными названиями.
- Наведение на среднюю карточку раскрывает гидравлику; изображение заменяется на разобранный насос. Уход курсора проверен отдельно.
- Tab переводит фокус к подкатегориям; Escape закрывает панель и возвращает фокус на исходную кнопку.
- Боковые карточки остаются интерактивными: проверено переключение с гидравлики на двигатель наведением на левую полосу. Закрытая внутренняя панель исключена из фокуса и accessibility tree через inert.
- Переход «Коленчатые валы» показывает один соответствующий товар из текущего каталога.
- Проверены размеры 320, 390, 760, 768, 1440 и 1920 px. Горизонтального переполнения нет; изображения, ссылки и CTA не пересекаются.
- На мобильных ширинах карточки располагаются в одну колонку; раскрытие не перекрывает соседние карточки.
- Просмотрены первый и последний ряды, длинное название «Рабочее оборудование». Исправлено попадание края соседней иллюстрации в карточку колёс из исходного спрайта.
- Ошибок в консоли браузера не обнаружено. Синтаксис app.js проверен через node --check.
- Отключение анимации при prefers-reduced-motion сохранено в CSS; отдельная эмуляция этого режима не выполнялась.

После перехода на гармошку повторно проверены 1440 и 768 px: соседние карточки в одном ряду, раскрытие из средней и крайней позиции, вертикальные названия, отсутствие жёлтой рамки и горизонтального переполнения.

Дополнительно подготовлен qa/category-cards.cjs для автономного запуска Playwright. В текущей песочнице отдельный Chromium не запускается из-за запрета macOS MachPortRendezvous; проверки выполнены во встроенном браузере. Автономный набор не помечен как прошедший.

Иллюстрации являются дизайнерской визуализацией, а не технической схемой. Список подкатегорий требует согласования с владельцем.
