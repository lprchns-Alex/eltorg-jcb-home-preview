# Карусель популярных товаров

Проверено 17 сентября 2026 в Codex In-app Browser через CUA / Playwright.

- Шесть исходных товаров: распределитель, коленвал, стартер, главная пара, генератор, натяжитель. Дополнительные цены и остатки не выдумывались.
- На ширине 1440 px видны ровно три карточки, две страницы. Стрелка переключает на вторую тройку и циклически возвращает к первой.
- После выхода указателя и фокуса из блока зафиксирована автоматическая смена с первой страницы на вторую. Интервал в коде 6000 мс.
- Кнопка паузы переключает aria-pressed и доступное имя. При ручной паузе горизонтальное перелистывание остаётся доступным.
- На 390 px виден один товар и шесть страниц; горизонтальная прокрутка перевела со второго товара на третий.
- На 800 px видны два товара, три страницы; при изменении ширины сохраняется группа текущего товара. ArrowRight на контейнере перевёл со второй страницы на третью.
- На 320 px горизонтального переполнения страницы нет, видна одна карточка.
- Кнопка заявки у генератора открывает форму с выбранным генератором, Escape закрывает её. Форма не отправлялась.
- Скрытые карточки исключены из клавиатурной навигации через inert; пагинация синхронизируется с нативной прокруткой.
- Ошибок браузерной консоли не обнаружено; node --check app.js проходит.

Пауза за пределами экрана, при скрытой вкладке, при фокусе и наведении реализована в контроллере. Режим prefers-reduced-motion отключает автоматический запуск и плавное перелистывание; отдельная эмуляция этого режима не выполнялась.
