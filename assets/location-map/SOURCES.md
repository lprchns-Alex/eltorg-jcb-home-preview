# Location map

Static preview of the neighborhood around Domostroitelnaya Street, 16,
Saint Petersburg. No third-party map requests are made by the page.

- Map tiles: https://tile.openstreetmap.org/12/{x}/{y}.png
- Zoom 12; x 2389-2397; y 1185-1188; downloaded 2026-09-30.
- Map data: OpenStreetMap contributors, ODbL.
- Attribution: https://www.openstreetmap.org/copyright (also visible on the page).
- Address coordinates: 60.072751, 30.373307.
- Coordinate source: https://yandex.com/maps/?text=60.072751%2C+30.373307

The 256px tiles are displayed as a CSS grid, without raster modifications.
CSS desaturates and fades the map. The marker and tiles share a fixed anchor
at the address, with horizontal centering preserved at responsive widths.
