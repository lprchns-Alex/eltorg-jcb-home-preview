# Parts manufacturer logos

Downloaded 2026-09-30 for the client preview. Trademarks belong to their
respective owners. Shapes are original artwork, not recreated with fonts.
CSS masks apply the requested black/yellow presentation.

- JCB: reused from ../equipment-brands/jcb.svg; see that directory's SOURCES.md.
- Perkins: https://commons.wikimedia.org/wiki/File:Perkins-Logo.svg
- Gates: https://upload.wikimedia.org/wikipedia/en/5/5c/GatesCorporation_Logo.svg
- Timken: https://www.timken.com/wp-content/uploads/2026/06/timken-logo.svg
- Husco: https://husco.com/wp-content/themes/cb_lightning/assets/images/layout/husco_logo.svg
- Carraro: inline SVG .logo-carraro from https://www.carraro.com/
- ZF: https://www.zf.com/master/media/toolbox/assets/img/ZF_logo_STD_Blue_3C.svg
- SKF: https://commons.wikimedia.org/wiki/File:SKF_logo.svg
- Donaldson: inline SVG .nav-logo from https://www.donaldson.com/
- Bosch: inline SVG, viewBox 0 0 433 97, from https://www.bosch.com/

Inline SVGs were extracted with an HTML parser. Carraro's HTML-lowercased
viewbox attribute was normalized to viewBox for use as a standalone asset.
