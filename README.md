# Эльторг: версия для заказчика

В публикации доступны только:

- Главная: index.html#home
- Каталог товаров: index.html#catalog
- Схема JCB с деталями снизу: pins-bushings-stacked.html#all

Карточки товара открывают запрос подбора, а не отдельную страницу.
Другие страницы и варианты схем не включены в публикацию.

Ветка client-preview предназначена для GitHub Pages. Полная рабочая версия
сохранена отдельно в локальной папке home-preview.

Товарные данные предварительные. Цены и совместимость требуют подтверждения.
Для брендов кроме JCB товарная выгрузка пока не добавлена.
